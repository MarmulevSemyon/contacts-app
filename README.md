# Contacts App / Контакты

Приложение для просмотра контактов устройства с возможностью звонков по нажатию на контакт.

## Возможности
- Просмотр контактов устройства
- Совершение звонков прямо из приложения
- Обработка разрешений
- Поиск по имени и номеру телефона

## Технологии
- Kotlin
- Jetpack Compose
- ViewModel
- ContentResolver

## Установка
1. apk файл можно найти и скачать в папке \apk или или же по [ссылке](https://github.com/MarmulevSemyon/contacts-app/blob/master/apk/ContactApp.apk)

## Разрешения
Приложение запрашивает:
- Чтение контактов
- Совершение звонков
